# Hudson Terminal

A free, clutter-free university schedule organizer — courses, calendar, syllabus tracking, and office hours, all in a single page. No sign-up, no install, no server.

**[Live app →](#)** *(replace this link with your GitHub Pages URL once it's live — see below)*

## Features

- **Calendar** — Month, Week, and Day views with smooth swipe/scroll navigation (touchpad and mouse wheel both work)
- **Courses** — add/remove courses, each with its own color; non-course events get a random color automatically
- **Overlapping events** — laid out side-by-side so nothing gets hidden behind another event
- **Recurring events** — daily, weekly, or monthly
- **Syllabus tracker** — per-course topic checklist
- **Office hours** — precise start/end times per course, shown on a weekly grid
- **Sticky notes** — a quick scratchpad in the sidebar
- **Dark and Light mode**, plus a custom background color picker

## Your data stays on your device

This app has **no server, no database, and no accounts**. Every course, event, and note you add is saved only in your own browser's local storage, on your own computer. Nothing is ever uploaded anywhere.

That also means:
- If multiple students use the same hosted link, **each person's schedule is private to their own browser** — no one can see anyone else's data.
- Your data **does not sync** between devices or browsers. If you use this on your phone and your laptop, they'll have separate, independent schedules.
- Clearing your browser's site data (or using a private/incognito window) will erase what you've entered.

## Using it

Just open the page — either the hosted link above, or by downloading `index.html` from this repo and opening it directly in any browser (double-click it, no install needed).

## Running it yourself / hosting your own copy

1. Fork or download this repository.
2. If hosting on GitHub Pages, the app must be named `index.html` at the repo root (it already is).
3. Enable GitHub Pages in the repo's Settings → Pages → set source to your default branch, root folder.
